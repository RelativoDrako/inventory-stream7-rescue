## Operating note

The repository is intentionally staged:

- inventory first
- assessment second
- reporting third
- optimization only after evidence exists
- invasive changes only after review

## Menu hint rule

Every launcher in this repository should:
- show a short execution hint on startup
- suggest `help`
- remind the operator to run inventory first
- disclose output paths for reports and logs
