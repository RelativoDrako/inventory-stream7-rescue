# Windows PowerShell 4 Legacy Guide

## Why this lane exists
Some environments still remain on older Windows baselines where PowerShell 4 is the realistic compatibility ceiling.

This legacy lane exists to provide:
- minimal inventory
- bounded assessment
- report generation
- modernization recommendations

## What it avoids
- dependence on newer cmdlets unavailable in PS4
- pretending legacy systems should be modernized blindly

## Suggested flow
1. `probe`
2. `assess`
3. `report`
4. `flow`
5. review modernization recommendations
