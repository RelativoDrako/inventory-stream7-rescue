# Linux General Guide

## Purpose
The Linux general lane inventories the machine, classifies its architecture, evaluates likely use cases, and generates executive/technical reports.

## Supported architecture intent
- x86 32-bit
- x86_64
- armhf
- arm64

## Suggested flow
1. `probe`
2. `assess`
3. `report`
4. `flow`
5. review outputs before any optimization

## Expected outputs
- probe report
- assessment report
- executive report
- operational flow / optimization recommendations
